# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements,
enhancements, and ideas are welcome.

## How to Contribute

Thank you for your interest in contributing to this project!
We value all forms of contribution from our community.

### Types of Contributions

#### 🐛 Bug Reports
If you find a bug, please open an issue with:
- A clear description of the problem
- Steps to reproduce the issue
- Expected vs actual behavior
- Your environment details

#### 🔧 Bug Fixes
If you have fixed a bug:
1. Fork the repository
2. Create a new branch: `git checkout -b bug-fix-description`
3. Make your changes
4. Commit: `git commit -m "Fix: description of bug fix"`
5. Push: `git push origin bug-fix-description`
6. Open a Pull Request

#### 📚 Documentation Improvements
Good documentation helps everyone. Feel free to:
- Fix typos or grammar errors
- Improve clarity of existing documentation
- Add missing documentation

#### ✨ Enhancements
Have an idea to improve the project?
1. Open an issue first to discuss the enhancement
2. Once approved, fork and implement
3. Submit a Pull Request with a clear description

#### 💡 Ideas
Share your ideas by opening a GitHub Issue with the label `enhancement`.
