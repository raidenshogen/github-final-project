# Simple Interest Calculator

## Project Description
This project provides a simple interest calculator implemented as a Bash script.
It takes user input for principal amount, rate of interest, and time period,
then computes and displays the simple interest.

## Project Name
Simple Interest Calculator

## Author
Zineb Nafil

## License
Apache License 2.0

## Purpose
This calculator helps users quickly compute simple interest using the formula:
Simple Interest = (Principal × Rate × Time) / 100

## Technologies Used
- Bash Scripting
- Git & GitHub

## How to Use
1. Clone the repository
2. Run the script: `bash simple-interest.sh`
3. Enter the required inputs when prompted
